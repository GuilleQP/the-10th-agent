Group Size — does a bigger majority resist the truth?

One locked dissenter (the truth) faces a majority of size N holding a false belief. We sweep N in powers of two and measure how much of the majority is converted. If the spiral of silence is real, conversion should fall as N grows.

Conversion vs. majority size

Conversion is measured only over agents that genuinely started with the false belief: any majority agent that argued the truth in epoch 1 before the dissenter spoke never held the belief, so it's dropped from the denominator (see “Pre-committed” below). This keeps a single early-breaker from invalidating a large-N run.
